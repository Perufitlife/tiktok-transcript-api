# TikTok transcript API: video captions to text and JSON, no login

How to get the transcript of any public TikTok video as clean text plus timed segments, without a TikTok developer account, without signing in and without running your own scraper.

This repo is a short guide with real output. The transcripts come from the Apify Actor [TikTok Transcript Scraper](https://apify.com/renzomacar/tiktok-transcript-scraper), which reads the captions TikTok already has for each video: the subtitles TikTok generates from the speech, or the captions the creator wrote. No cookies, no account, no API key from TikTok.

## Why not the official API

- The **Display API** (Login Kit) only lists the videos of the user who signs in to your app, and it has no transcript field.
- The **Research API** has a `voice_to_text` field, but access is limited to approved non-profit academic researchers.
- A plain HTTP request to a video page sometimes gets a small proof-of-work challenge page instead of the video data. The Actor handles that and reads the caption file linked from the page.

`transcript` joins the lines into sentences and starts a new paragraph where the speaker pauses, ready for a summary, an LLM prompt or a search index. `segments` keep the timing in seconds, for subtitles or for quoting the exact second something is said.

## Call it from code

You need an Apify account and its API token (`APIFY_TOKEN`).

curl, with the transcript back in the same request:

```bash
curl -X POST "https://api.apify.com/v2/acts/renzomacar~tiktok-transcript-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "content-type: application/json" \
  -d '{"videos":["https://www.tiktok.com/@chefchrischo/video/7036492957121514798"],"includeSegments":false}'
```

Python: the opening line (the hook) of each video next to its plays, the usual first step when studying what makes short videos work:

```python
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("renzomacar/tiktok-transcript-scraper").call(run_input={
    "videos": [
        "https://www.tiktok.com/@chefchrischo/video/7036492957121514798",
        "https://www.tiktok.com/@girlandthekitchen/video/7460657174600027434",
        "https://www.tiktok.com/@yinrun_hello/video/7479144302149438742",
    ],
})
rows = [r for r in client.dataset(run["defaultDatasetId"]).iterate_items() if not r["error"]]
for r in sorted(rows, key=lambda r: r["plays"] or 0, reverse=True):
    hook = " ".join(s["text"] for s in r["segments"] if s["start"] < 3)
    print(f'{r["plays"]:>10,}  @{r["authorUsername"]}: {hook}')
```

JavaScript: an SRT subtitle file from the timed segments:

```js
import { writeFileSync } from "node:fs";
import { ApifyClient } from "apify-client";

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor("renzomacar/tiktok-transcript-scraper").call({
  videos: ["https://www.tiktok.com/@ayomadelyn/video/7590966106844630302"],
});
const [video] = (await client.dataset(run.defaultDatasetId).listItems()).items;
const ts = (s) => new Date(s * 1000).toISOString().slice(11, 23).replace(".", ",");
const srt = video.segments
  .map((s, i) => `${i + 1}\n${ts(s.start)} --> ${ts(s.start + s.duration)}\n${s.text}\n`)
  .join("\n");
writeFileSync(`${video.videoId}.srt`, srt);
```

## Input fields

| Field | What it does |
|---|---|
| `videos` | One per line: `tiktok.com/@user/video/…`, a short share link (`vm.tiktok.com/…`, `tiktok.com/t/…`) or the numeric video ID. The same video given twice is read once. |
| `language` | Two-letter code such as `en`, `es`, `pt`. Empty = the language spoken in the video. |
| `ifLanguageMissing` | `original` returns the video's own language, `skip` returns a free row with the reason. |
| `includeSegments` | Add the timed lines (default `true`). Turn off for smaller files when you only need the text. |
| `proxyConfiguration` | Not needed. Public pages are read directly, and Apify Proxy is used on its own if TikTok stops answering. |

## Good to know

- The transcript comes from TikTok's own captions. Videos with no speech (music only, text on screen only) and videos whose creator turned captions off have none; they come back as free rows with the reason.
- Translations exist only when TikTok made one for that video, usually English. `availableLanguages` lists them; nothing is machine-translated by the Actor.
- Private and removed videos need a login, so they come back with an `error` and are not charged.
- Counts are the ones TikTok shows on the page, so large numbers come rounded (6000000, 7200000).
